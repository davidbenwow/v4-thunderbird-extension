# Download-page images

The install page (`docs/index.html`) shows a screenshot slot for each step.
Drop the screenshots here with these exact filenames and they appear automatically
(until then, each slot shows a dashed placeholder):

- `step-1.png` — downloading the add-on
- `step-2.png` — Config Editor: `xpinstall.signatures.required` → false
- `step-3.png` — Add-ons and Themes → gear → Install Add-on From File
- `step-4.png` — the add-on's Preferences tab with the API key field

`icon-96.png` is the page logo (copied from `src/images/icon-96.png`).
